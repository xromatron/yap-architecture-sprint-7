# Задание 1. Разработка проверочного листа по безопасности данных

## 1. Проанализируйте диаграмму и описание системы PropDevelopment
Классифицируйте данные, с которыми работает компания, по стандартам ISO/IEC 27001 и 27002. Распределите их по четырём категориям:
- публичные данные,
- внутренние данные,
- конфиденциальные данные,
- секретные данные.

Данные объектов недвижимости - публичные
Данные по сделкам - конфиденциальные
Данные клиентов - конфиденциальные
Данные собственников - конфиденциальные
Данные услуг ЖКХ по собственникам - внутренние
Данные бухгалтерского учета - конфиденциальные
Данные сервиса аутентификации - секретные
Системные и технические данные - внутренние

## 2. Определите риски для каждой категории данных
В каждой категории данных могут существовать следующие риски:
- утечка данных,
- потеря данных,
- искажение данных,
- некачественные данные,
- обесценивание данных.

Секретные:
- утечка - доступ злоумышленников
- потеря - невозможность доступа к системе реальных пользователей
- искажение - получение доступа реальных пользователей к областям, которые не должны быть им доступны
Конфиденциальные:
- утечка - утечка персональных данных и данных по сделкам и платежам приведет к штрафам и потере доверия клиентов
- потеря - невозможность работы
- искажение - некорректное отображение информации, недовольство клиентов
Внутренние:
- потеря - недоступность данных для собственников об услугах ЖКХ
- искажение - некорректное отображение информации, недовольство клиентов
Публичные:
- потеря - невозможность работы
- искажение - несанкционированное изменение данных о квартирах может ввести в заблуждение клиентов и нанести ущерб репутации

## 4. Дайте оценку каждому риску
В качестве шкалы используйте категории «незначительный-значительный-критический».
## 5. Визуализируйте результаты анализа в виде mindmap
Для создания mindmap используйте draw.io. В центре разместите блок «Безопасность данных». От него протяните стрелочки и разместите следующий уровень — выделенные категории данных. На следующем уровне укажите, какие именно данные компании относятся к этой категории. Для каждой категории данных укажите риск и присвойте ему оценку. На последнем уровне объясните, почему вы оценили риск именно так.
